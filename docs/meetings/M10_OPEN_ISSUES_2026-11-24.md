## A. 전투·성장 구조 (가장 큼 — 결정 필요)

| # | 문제 | 근거 |
|---|---|---|
| A1 | **레벨이 장비를 압도** | HP를 올리는 건 레벨뿐(장비 HP 0). 방어 장비 차이가 작음(일반 7 → 레전 12, 부위당 +5). Lv12는 HP +440·공/방 +22. Lv1 레전 풀셋(150/49/HP100)은 오크 1대에 사망, Lv12 기본 장비(72/59/HP540)는 3.6대 버팀 |
| A2 | **초반 사냥 불가** | Lv1 기본 장비 vs 1층 goblin(200/50/10): 5대·50Tick, 받는 피해 65, 휴식 65Tick → 1마리 ≈ 115Tick에 XP 10. Lv5(250XP)까지 ≈ 2,900Tick > MIA 2,880 |
| A3 | **미믹이 수문장** | Lv5 + Rare(78/49/HP260) vs 미믹(800/90/14): 내가 13대, 미믹은 7대면 날 죽임. 포션 없이 계산상 불가 (메모 2-7·7-12) |
| A4 | **사냥 vs 하강 딜레마** | 일반 몹 XP 10. XP를 올리면 Tick 압박이 사라지고, 내리면 레벨이 안 따라옴 (메모 9-3·8-7) |
| A5 | **휴식 회복이 고정값** | 10Tick당 +10(5층 보스 후 +20), 최대 HP 비율 아님 → Lv12(HP 540)는 꽉 채우는 데 540Tick. 결정 14(Tick 2배) 대상인데 미반영. 코드 하드코딩(`PlayerTurnActor.ResolvePendingRestHeal`) |
| A6 | **뺄셈 피해 공식** | 몹 공격력이 높을수록 방어 몇 점 차이가 무의미 → A1을 키움 |
| A7 | **포션 의존** | 레전 세트도 포션 없이는 보스 불가 (메모 2-7). 포션 절반 즉시(결정 42) 체감 미검증 |

조정 축 후보: **장비**(방어구 HP 추가 / 방어 범위 확대) → **레벨**(HP만 / 공·방 증가 축소) → **휴식**(최대 HP 비율) → **초반 몹·미믹 재계산**. Claude 추천 순서: 장비 → 레벨 → 휴식 → 몹.
