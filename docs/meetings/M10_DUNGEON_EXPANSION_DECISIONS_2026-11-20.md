## 1. 확정 결정

| # | 항목 | 결정 |
|---|---|---|
| 1 | 층 수 | 던전을 **10층**까지 확장 |
| 2 | 보스 | **5층 보스 = 미믹**(chest_mimic), **10층 보스 = 오크**(orc_warrior). 기존 5층 오크 방향은 10층으로 이동. 미믹은 16×16이라 표시 크기는 구현 때 검토 |
| 3 | 시간 | 시계는 **24시간 유지**, **1Tick = 30초**로 바꿔 행동 수를 2배(2,880Tick)로. 시간대 구조(자정 문턱 등)는 그대로 |
| 4 | 6층 개방 | **원정마다 5층 보스를 잡아야** 6층으로 내려갈 수 있다 (영구 개방 아님) |
| 5 | 타일 | 6~10층은 **다른 타일** 사용 (0x72 팩 내) |
| 6 | 몹 | **0x72 팩의 몬스터 스프라이트를 전부 사용**. 현재 단일 몹 → 여러 종을 층별로 돌려 쓴다. 일반 / 엘리트 / 보스는 서로 다른 몹 |
| 7 | 심야 몹 | chort·imp·big_demon 심야 전용 구성 유지 (big_demon은 보스로 쓰지 않음) |
| 8 | 엘리트 | 일반 몹보다 **체력·공격력이 높다**. 행동 패턴은 미정 |
| 9 | 루팅 | 깊은 층은 **가장 낮은 등급 확률에서 떼어 높은 등급에 더한다**. 필요하면 전체 확률표 재조정 |
| 10 | 탈출 스크롤 규칙 | 사용 규칙(각 층 시작 방, 체류)은 그대로. 대신 가치를 높인다 |
| 11 | 탈출 스크롤 획득 | **상점 구매 폐지.** 획득처는 **상인 퀘스트 보상** 또는 **엘리트 몹 드롭**뿐. 엘리트 드롭 스크롤은 **원정이 끝나면 사라짐** |
| 12 | 세이브 변환 | 변환 시 창고·출격 가방의 **탈출 스크롤 전부 삭제** |
| 14 | 분 단위 규칙 | **분으로 유지**(Tick 수는 2배). 탈출 스크롤 체류 20분 = 40Tick, 공격 5분 = 10Tick, 보험 대기·유예도 시간 기준 그대로. 이동(1칸 = 1Tick = 30초)만 상대적으로 싸져 10층 탐험 여유를 만든다 |
| 13 | 퀘스트 | 기존 5층 보스 관련 퀘스트(q02·q04a·q06a)는 그대로. 퀘스트는 이후 계속 추가 |

### 결정 15 — 몹 배치 (초안 확정, Play 후 수정 전제)

| 구분 | 1~4층 | 6~9층 |
|---|---|---|
| 일반 | goblin, tiny_zombie, tiny_slug, skelet, slug, zombie, muddy | swampy, ice_zombie, orc_shaman, wogol, pumpkin_dude, doc, angel |
| 엘리트 | masked_orc, big_zombie | ogre, necromancer |
| 보스 | 5층 미믹 | 10층 오크(orc_warrior) |
| 심야 | chort, imp, big_demon (전 층 공통) | |

- 1~2층은 작은 몹 위주, 3~4층에 중간 몹. 6~9층은 신규 몹만 사용(타일 변경과 함께 "새 구역").
- 층당 일반 몹 종류 수·엘리트 수는 **임시값을 CSV로** 두고 Play 후 조정 (예: 층마다 일반 2~3종 랜덤, 엘리트 0~2마리).
- 사용자 메모: "안 어울리면 수정하면 되는 문제" — 배치는 데이터(CSV)로만 바꿀 수 있게 구현.

### 결정 16 — 6~10층 타일

0x72 v1.7은 바닥·벽 세트가 사실상 하나뿐이므로 **새 에셋 없이**:
1. **색 변경**: 같은 타일에 층 구간별 색조(tint)를 입힌다 (6~10층은 어둡거나 푸른/붉은 톤, 수치는 CSV 임시값)
2. **장식 변경**: 같은 팩의 장식으로 분위기를 바꾼다 — wall_goo(점액 벽), 빨간 배너·분수, floor_spikes(가시 장식) 등

다른 에셋 팩은 쓰지 않는다(라이선스·크레딧·규격 부담). 이후 직접 그린 타일로 교체할 수 있게 층 구간별 타일 설정을 데이터로 분리한다.

### 결정 17·18 (2026-11-20, Codex 구현 검토 후)

- **17 엘리트 표시**: 특별할 필요 없이 "아 쟤구나" 정도. 크기 배율(`m10_enemies.csv` visual_scale 1.15~1.2) + 옅은 붉은 색조(`m10_dungeon.csv` elite_tint_r/g/b, %). 패턴은 여전히 일반과 동일

### 결정 29 — 경험치 (2026-11-23)

- 획득: **처치 경험치 + 층 첫 도착 경험치**. 층 도착이 **정해진 Tick 이내면 추가 경험치**(빨리 내려갈수록 보상)

| 엘리트 처치 (3층부터) | 40 | 90 |
