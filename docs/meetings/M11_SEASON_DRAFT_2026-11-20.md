# M11 계절 시스템 초안 (2026-11-20)

> 상태: **아이디어 확정, 세부 미정.** M10 Play 검증 후 M11(시간대·제단) 회의에서 이어서 정한다.
> 계기: 라스푸티차(러시아 진흙철) 얘기 → 날짜 개념이 있으니 인게임 계절을 넣자.

## 확정 (사용자, 2026-11-20)

| # | 항목 | 결정 |
|---|---|---|
| S1 | 계절 주기 | **원정에서 소모한 Tick 30,000마다** 계절이 바뀐다 (원정 횟수 기준 아님). 꽉 채운 원정(2,880Tick) 기준 약 10~11회, 짧은 원정이면 그보다 많이 |
| S2 | 순서 | 봄 → 여름 → 가을 → 겨울 (반복) |
| S3 | 봄 | **비** — ① **명중·회피 감소**(미끄러움) + ② **진흙 칸**(일부 바닥만 이동 비용 증가, 피해서 갈 수 있음). 둘 다 적용 |
| S4 | 여름 | **더위** — 일반 데미지 감소, 또는 **쉬지 않고 계속 이동하면 화상(열사) 데미지**. 완급 조절용으로 **그늘·물 타일** 추가(그 위에서는 더위 누적 해소) |
| S5 | 가을 | **디버프 없음** (쉬는 계절) |
| S6 | 겨울 | **동상** — **이동 Tick 증가가 기본** (추가 효과는 이후 검토) |
| S7 | 계절별 몹 | 계절마다 몹 구성·비중이 달라진다. 최소한 **몹 색깔만 바꿔도** 변화가 보이게 |
| S8 | 심야와 관계 | **계절 효과 + 심야 효과가 겹친다** (둘 다 적용) |
| S9 | 드랍 | 계절에 따라 드랍 아이템 일부 변경 (계절 한정 잡템·재료 등) |

## 미정

- [ ] 봄: 명중·회피 감소 폭, 진흙 칸 비율·이동 비용 (임시값 CSV)
- [ ] 여름: 데미지 감소 / 화상 중 최종 선택 (또는 둘 다). 화상 조건(연속 이동 몇 칸·몇 Tick), 데미지량, 휴식·그늘·물 타일에서 해소 방식
- [ ] 여름 그늘·물 타일: 0x72 팩에서 무엇으로 표현할지(분수·물웅덩이 등), 층당 개수
- [ ] 겨울 동상 이동 Tick 증가 폭 (예: 1 → 1.5? 임시값 CSV), 추가 효과 여부
- [ ] 계절 몹: 색조만 / 몹 구성 비중까지 (예: 겨울엔 ice_zombie 비중 증가)
- [ ] 계절 한정 드랍 목록
- [ ] 계절 표시 UI (영지·던전 시계 옆)
- [ ] 누적 Tick 기준: 결정 22(스크롤 충전 10,000Tick)와 같은 누적값을 쓸지
- [ ] 세이브: 누적 Tick·현재 계절 저장 (버전 변경 필요 여부)
- [ ] 계절 효과 수치 전부 CSV
