## 2. 가방 = 보관함

| # | 항목 | 결정 |
|---|---|---|
| 8 | 가방 열기 | Stash(또는 상위 가방)의 가방을 더블클릭하면 그 가방 격자가 열리고 안에 보관 |
| 9 | 중첩 | **최대 4단계.** Stash 바로 안의 가방 = 1단계 … 4단계 가방 안에는 가방을 넣을 수 없다 |
| 10 | 자기 포함 금지 | 가방을 자기 자신이나 자기 하위 가방 안에 넣을 수 없다 |
| 11 | 내용물 있는 가방 장착 | 내용물 그대로 출격 가방이 된다 |
| 12 | 내용물 있는 가방 판매 | 불가 + "가방을 비워주세요" |
| 13 | 던전에서 하위 가방 | 출격 가방 안의 가방은 **던전에서 열 수 없다.** 아이템으로만 취급(이동·버리기 가능, 내용물 유지). 영지에서만 열린다 — 무게·실제 아이템 제한 없이 던전에서 열면 공간이 무한해지므로 막는다 |
| 14 | 사망·MIA | 출격 가방과 그 안 하위 가방 내용물 전부 손실 (기존 규칙) |
| 15 | 보험 | 가방 보험은 가방만. 내용물은 대상 아님 (기존 규칙). 반환되는 가방은 빈 가방 |

## 3. 임시 보관함

| # | 항목 | 결정 |
|---|---|---|
| 16 | 생성 조건 | Stash에 자리가 없을 때 들어오는 아이템(생환 획득품, 구매품, 보험 반환, 퀘스트 보상, 장착 해제, 마이그레이션 넘침)은 **임시 보관함**으로 |
| 17 | 형태 | 목록형, 칸 제한 없음. Stash·가방으로 옮기기, 판매 가능 |
| 18 | 출격 차단 | 임시 보관함에 아이템이 있으면 **출격 불가** + "임시 보관함을 정리하세요" |

## 4. 추가 확정 (2026-11-17)

| # | 항목 | 결정 |
|---|---|---|
| 19 | 운반 퀘스트 | q03·q05a·q06b 판정에 **하위 가방 내부 아이템도 포함** |
| 20 | 가방 장착 해제 | 내용물을 가방 안에 그대로 유지한 채 가방 전체를 Stash로 이동. 공간이 없으면 임시 보관함 |
| 21 | 임시 보관함 삭제 | 삭제 허용. 확인창 필수. 내용물 있는 가방은 내부 아이템도 함께 삭제된다고 별도 경고 |
| 22 | 상점 판매 UI | 아이템별 판매 버튼을 **판매 바구니 격자**로 교체. Stash에서 상인에게 옮기는 방식 |
| 23 | 판매 확정 | 바구니 이동만으로는 Gold가 변하지 않으며 `판매 확정` 때 원자적으로 지급. 확정 전 Stash로 회수 가능 |
| 24 | 판매 제약 | 내용물 있는 가방은 이동 불가, 보험 아이템은 경고, 이동·판매 모두 0Tick |
| 25 | 판매 중 종료 | 미확정 거래를 취소하고 판매 바구니 아이템을 원래 위치로 복구 |
| 26 | 판매 바구니 크기 | 좁은 UI 폭에 맞춘 **5×20**, 세로 스크롤. Stash와 별도 설정값 |
| 27 | 긴 격자 조작 | 휠 감도를 높여 긴 격자를 빠르게 탐색하고, 아이템을 드래그한 채 위·아래 가장자리에 두면 해당 방향으로 자동 스크롤 |
| 28 | Stash 가방 열기 | 가방 더블클릭 시 Stash·판매 바구니는 유지하고 해당 가방 크기의 별도 창을 연다. 더블클릭·드래그로 Stash ↔ 열린 가방 이동 |
| 29 | 판매 드래그 | 판매 탭에서 Stash ↔ 판매 바구니를 드래그 앤 드롭. 판매 확정 전 Gold 불변, 실패 시 원위치 |
| 30 | 다중 가방 창 | 가방마다 이동 가능한 독립 창을 열며 최대 5개. 6번째 창을 열면 가장 먼저 연 창을 닫는다. 가방 속 가방도 새 창으로 열고 열린 가방 간 드래그를 허용한다 |
| 31 | 가방 외부 크기 | 외부 크기 = 내부 수납 크기(Normal 4×2, Rare 3×3, Epic 5×3, Unique 4×5). 하위 가방은 용량 압축 이득 없이 정리 용도 |
| 32 | 가방 드롭 보정 | 가방 격자 영역에 드롭하면 아이템 전체 크기를 고려해 가장 가까운 유효 시작 칸으로 스냅. 정확한 셀 조준을 요구하지 않음 |
| 33 | 루팅 장비 직접 장착 | 상자·바닥 더미·보스 전리품의 무기·방패·갑옷·가방 더블클릭 = 즉시 장착 2Tick, 기존 장비는 그 루팅 격자로. 교환 공간 없으면 상태 불변·0Tick. 잡템·소모품은 기존대로 획득 1Tick. 이유: 결정 31로 큰 가방을 출격 가방에 넣을 수 없어 직접 장착이 필요 (사용자 확정 2026-11-18) |
| 34 | Stash 직접 장착·해제 | 영지 Stash에서 바로 장착(기존 장비는 Stash로), 해제도 Stash로. Stash가 차면 임시 보관함 (사용자 확정 2026-11-18) |
| 35 | F9 생성 위치 | 던전은 발밑 5×5 바닥 더미, 영지는 Stash(넘치면 임시 보관함). QA 편의 목적 (사용자 확정 2026-11-18) |
| 36 | 드롭 대상 판정 | 드래그 미리보기·드롭은 **화면에서 맨 위에 보이는 격자**만 대상으로 한다. 겹친 아래 격자로 넘어가지 않고, 격자가 아닌 곳이면 취소 (BUG-045) |
| 37 | 가방 아이콘 드롭 | 영지에서 아이템을 닫힌 가방 아이콘 위에 놓으면 그 가방 빈 공간에 자동 배치(회전 포함). 가방 아이콘에 초록/빨강 미리보기. 중첩 4단계·자기 포함 규칙 유지. 던전은 결정 13에 따라 미적용 (사용자 확정 2026-11-18) |
