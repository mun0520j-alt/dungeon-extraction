# 추가 지시 — M9 영지 UI 정렬 (2026-11-17)

> 기존 지시서 `docs/handoff/Codex_작업지시_2026-11-17_M9Stash격자.md`에 **단계 5.5 "영지 UI 정렬"**로 추가한다. 이 파일을 `docs/handoff/`에 함께 커밋한다.
> 지금 진행 중인 단계를 끝내고 커밋한 뒤 착수한다. 새 Canvas 금지(BUG-044), OnGUI·uGUI 겹침 금지.

## 배경 (사용자 Play 스크린샷, 2026-11-17)

1. 화면 중앙 "원정 준비/결과" 창(uGUI)이 가운데 OnGUI 패널(보험·Stash 목록) 아래에 깔려 오른쪽 절반이 가려진다. OnGUI는 항상 uGUI 위에 그려진다.
2. 오른쪽 패널에서 Stash 격자 맨 아래 행이 버튼에 덮이고, "아이템을 선택하세요" 문구가 격자 위에 겹친다. 10×12로 커지면 더 심해진다.
3. Stash가 세 곳(상인 판매 목록, 가운데 텍스트 목록, 오른쪽 격자)에 중복 표시된다.

## 목표 배치 (3열, 1920×1080 기준, 서로 겹치지 않음)

```
┌ 상인 ──────────┐┌ Stash ───────────────────┐┌ 출격 준비 ──────────────┐
│ 판매/구매/퀘스트 ││ 정렬·부위·등급·★ 필터 한 줄 ││ 장착 장비 4칸            │
│ ─ 판매 탭:      ││                           ││ 출격 가방 격자           │
│   판매 바구니 격자││   Stash 격자 10×8~10×12   ││ 보험 (후보·대기·수령)     │
│   합계 · 판매 확정││   (가장 큰 영역)          ││ 선택 아이템 이름 + 버튼   │
│ ─ 구매 탭: 목록  ││                           ││ ─────────────────       │
│ ─ 퀘스트 탭     ││ 임시 보관함 (있을 때만)     ││ 원정 준비/결과 + 출격     │
└────────────────┘└───────────────────────────┘└─────────────────────────┘
```

| 열 | 내용 |
|---|---|
| 왼쪽 · 상인 | 탭 유지. **판매 탭 = 판매 바구니 격자 + 합계 + 판매 확정**(결정 22~25). 기존 아이템별 판매 버튼 목록은 제거. 구매·퀘스트 탭은 기존 유지 |
| 가운데 · Stash | Stash 격자 전용. 위에 정렬(등급순/종류순)·부위·등급·★ 필터 한 줄, `★ = 인레이드` 범례. 아래에 **임시 보관함**(비어 있지 않을 때만, 경고색 제목). 가방 더블클릭 시 열리는 하위 가방 격자도 이 열 안에서(격자 위 탭/브레드크럼 `Stash › 가방A › 가방B`) |
| 오른쪽 · 출격 준비 | 장착 장비 4칸 → 출격 가방 격자 → 보험 → 선택 아이템 이름·버튼(Stash로/장착/가방으로 등) → 맨 아래 **원정 준비/결과 + 출격 버튼** |

## 규칙

- **화면 중앙 단독 원정 준비/결과 창은 없앤다.** 같은 내용을 오른쪽 열 맨 아래 영역으로 옮긴다. 출격 차단 사유(임시 보관함 등)도 이 영역에 표시.
- **가운데 텍스트 Stash 목록 삭제.** 보험 UI는 오른쪽 열로 이동.
- 한 열 안에서 OnGUI와 uGUI를 섞지 않는다. 섞어야 하면 영역(Rect)을 겹치지 않게 분리하고 그 Rect를 한 곳(레이아웃 계산 함수)에서 만든다.
- 열 폭·높이는 화면 크기에서 계산하는 **레이아웃 함수 하나**에서 정한다. 하드코딩된 좌표 산재 금지. (MAINTAINABILITY 2장)
- 격자 칸은 48px 유지. 영역보다 크면 **그 영역만 스크롤**(페이지 전체 겹침 금지).
- 1920×1080, 1600×900, 1280×720에서 겹침 없음 확인. 1280×720은 스크롤로 해결해도 됨.
- 상인 판매 목록에 있던 ★·[보험] 표시는 판매 바구니 격자에서도 유지(격자 마커).
