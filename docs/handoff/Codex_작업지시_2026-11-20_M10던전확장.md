## 단계 (단계마다 커밋, 컴파일 확인)

### 1. 시간 단위: 1Tick = 30초 (결정 3·14)

- `DungeonClock.MinutesPerTick` 1 → **0.5**, `MIAThresholdTicks` 1440 → **2880** (24시간 유지)
- **분 단위 규칙은 분 유지 = Tick 값 2배**: `TickCost`에서 이동(`PerTileMove`)만 1 유지, 나머지(공격·장비·아이템·상호작용·줍기·버리기) 2배
- CSV Tick 값 2배: `escape_scroll_use/stay/lifetime_ticks`(2/40/100), `insurance_wait/claim_ticks`, 그 밖에 Tick 단위 CSV·상수 전부 grep해서 목록화 후 2배. **목록을 보고에 포함**
- 적 이동·공격 Tick, 휴식 회복, 보스 패턴 주기, M3 측정의 Tick 기준값도 같은 원칙
- 시계 UI·시간대(자정 문턱)는 분 기준이라 그대로여야 한다 — 회귀 확인
- M3 측정 CSV에 단위 변경 표시(버전 컬럼 또는 파일명) — 이전 데이터와 섞이지 않게

### 2. 10층 구조 (결정 1·2·4)

- `FinalFloor` 5 → **10** (config/CSV로). 보스 층은 데이터로: **5층 = 미믹(chest_mimic)**, **10층 = 오크(orc_warrior)**. 기존 5층 보스 로직은 10층 오크로, 5층에는 미믹 보스 아레나
- 보스 패턴은 **미정** → 두 보스 모두 기존 5층 보스 행동(단일 + 광역)을 그대로 쓰고, 수치만 CSV. 미믹 16×16 표시 배율은 CSV 임시값
- **6층 개방: 원정마다 5층 보스 처치 후에만** 6층 계단 활성. 처치 기록은 원정 단위(세이브 영구 아님)
- 5층의 기존 탈출 수단은 **변경하지 않는다**(사용자 확인 대기 — 보고에 "5층 생환 유지 여부" 질문으로 표시)
- 10층 = 최종 출구. `finalExit`·`ExpeditionManager` 최종층 판정 갱신
- 퀘스트(q02·q04a·q06a 등 "5층 보스" 조건)는 **그대로** — 미믹 처치가 기존 5층 보스 조건을 충족하는지 확인
- 층별 방 수·크기는 CSV(임시값: 6~9층은 4층 값 이상)

### 3. 몹 데이터화 (결정 6·7·8·15)

- 신규 `Assets/Resources/Data/m10_enemies.csv`: `enemy_id, sprite_key(0x72 이름), tier(normal/elite/boss/night), hp, attack, defense, move_cost_mult, behavior` — 기존 단일 적 수치를 기준값으로
- 신규 `m10_floor_spawns.csv`: 층별 일반 몹 후보·종류 수·마리 수, 엘리트 수(임시: 층당 일반 2~3종 랜덤, 엘리트 0~2)
- 배치(결정 15): 1~4층 일반 goblin·tiny_zombie·tiny_slug·skelet·slug·zombie·muddy / 엘리트 masked_orc·big_zombie. 6~9층 일반 swampy·ice_zombie·orc_shaman·wogol·pumpkin_dude·doc·angel / 엘리트 ogre·necromancer. 심야 chort·imp·big_demon 전 층(기존 심야 규칙 유지)
- **엘리트 = 체력·공격력 상향**(배율 CSV), 행동 패턴은 일반과 동일(패턴 미정). 시각 구분(크기·색·HP바 표시 중 하나, 임시)
- 애니메이션: 0x72 frames로 몹별 idle/run. 몹마다 AnimatorController를 수작업으로 만들지 말고 **스프라이트 키로 프레임을 찾는 공용 방식**(유지보수). 큰 스프라이트(16×28/32×36) 피벗·정렬 확인(goblin 파묻힘 선례 `EnemyTurnActor` 540줄 주석)
- 영웅 스프라이트(knight·elf·dwarf·lizard·wizzard)는 **쓰지 않는다**(미정)

### 4. 6~10층 타일 (결정 5·16)

- 신규 `m10_floor_themes.csv`: 층 구간별 바닥·벽 **색조(tint)**와 **장식 세트**(wall_goo, 빨간 배너·분수, floor_spikes 장식 등). 1~5층은 현재 그대로
- 새 에셋 팩 금지. 타일 설정을 데이터로 분리해 나중에 직접 그린 타일로 교체 가능하게
