# Codex 작업지시 — 레벨 곡선·포션 즉시 회복·보스 광역 이펙트·미믹 공격 애니 (2026-11-24)

근거: 결정 회의록 결정 41~44, M10 체크리스트 메모 8-2·8-6·8-7·8-10·8-11.
수치는 전부 CSV. 아래 값은 **임시** — 다른 수치 변경 금지.

## 1. 레벨 곡선 (결정 41)
- `m10_levels.csv`: Lv n의 `hp_bonus` = (n-1)×**40**, `attack_bonus`·`defense_bonus` = (n-1)×**2**. `cumulative_xp`는 그대로.
- `PlayerTurnActor.ApplyM10LevelUp`의 레벨업 즉시 회복 `gainedLevels * 30` **하드코딩 제거** → 레벨 CSV의 HP 증가량과 같은 값 사용.
- `m10_dungeon.csv` `fast_arrival_bonus_pct` 50 → **100**.
- 몹 스탯 변경 금지.

## 2. 포션 절반 즉시 회복 (결정 42)
- `m10_potions.csv`에 `instant_pct` 열 추가, 소·중·대 모두 **50**.
- 사용(2Tick 완료) 시 총 회복량 × instant_pct% 를 즉시 회복, 나머지를 `duration_ticks`(10)에 걸쳐 기존 방식으로.
- 회복 중 새 포션 사용: 남은 지속 회복은 버리고 새 포션의 즉시분 + 지속분으로 다시 시작.
- 사망 후 회복 금지(기존 가드 유지). 즉시 회복도 `[M10Potion]` 로그와 HUD에 표시.

## 3. 보스 광역 발동 이펙트 (결정 43)
- `EnemyTurnActor` 광역 발동(356행 부근) 순간: 광역 범위 전체에 **붉은 번쩍임 또는 폭발 이펙트**(0.3~0.5초) + **짧은 카메라 흔들림**.
- 기존 `HitImpactVfx` 등 재사용 우선. 새 Canvas·Singleton 금지. 흔들림 세기·시간은 상수/CSV로, Player 이동 카메라와 충돌하지 않게.
- 미믹·오크 둘 다 적용. 사용자 Play 피드백으로 조정 예정이므로 값 찾기 쉬운 곳에 둘 것.

## 4. 미믹 공격할 때만 열기 (결정 44)
- chest_mimic: idle·이동 = **닫힌 상자 1프레임**(`chest_mimic_open_anim_f0`), **공격(단일·광역 예고·광역 발동) 순간에만 open f0→f2** 재생 후 닫힘.
- `M10SpriteAnimation`에 공격 애니 1회 재생(끝나면 idle 복귀) 기능 추가 — 다른 몹은 공격 프레임이 없으면 기존 동작 유지.
- 카탈로그 빌더: chest_mimic `runFrames`도 닫힌 1프레임으로, 공격용 프레임 필드(예: `attackFrames`) 추가. Validate Data 갱신.
