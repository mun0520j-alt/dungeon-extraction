# Codex 작업지시 — F9 QA 패널 높이·잔여 Tick 값 (2026-11-25)

## 1. F9 패널이 짧아 아이템 목록이 한 줄만 보임 (사용자 스크린샷)
- 원인: `ExpeditionDebugCommands.Panels.cs` `DrawM6ItemPanel()` 9행 `height = Mathf.Min(620f, Screen.height - 32f)`.
  M10 QA 컨트롤(층·엘리트·던전 경과·레벨·경험치·포션·스크롤 상점)이 늘어나면서 620 안에서 아이템 스크롤뷰가 거의 0 높이가 됨.
- 수정:
  - 620 상한 제거 → 화면 높이에 맞게 `Screen.height - 32` (위아래 16 여백).
  - 아이템 목록 스크롤뷰에 최소 높이(예: 버튼 6줄 ≈ 200px) 보장. 화면이 작아 다 안 들어가면 **패널 전체를 하나의 스크롤뷰**로 감싸서 QA 컨트롤도 스크롤로 내려볼 수 있게.
  - 패널 폭 420은 유지 (필요하면 480까지). 닫기 버튼은 항상 보이게 스크롤 밖 하단 고정.
- QA 전용 코드(`#if UNITY_EDITOR || DEVELOPMENT_BUILD`) 그대로. 새 Canvas·Singleton 금지(IMGUI 유지).
