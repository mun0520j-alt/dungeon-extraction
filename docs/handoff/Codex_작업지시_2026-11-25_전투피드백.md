# Codex 작업지시 — 피해 숫자·전투 로그 (2026-11-25)

근거: 결정 회의록 결정 52. 사용자: "맞거나 때렸을 때 체력만 다는데, 로그 + 체력 - 이펙트 나오면 좋을 듯".

## 1. 피해 숫자 팝업
- `PlayerTurnActor.TakeDamage`·`TakeFixedDamage`, `EnemyTurnActor.TakeDamage`에서 실제 적용된 피해량을 **맞은 캐릭터 바로 위**에 `-N`으로 표시 (사용자 지정 위치).
  - 위로 0.5~0.7초 떠오르며 페이드아웃. 월드 공간 TextMesh 등 기존 방식(`HitImpactVfx`·보스 예고 라벨과 같은 계열) 사용.
  - 색: Player 피격 빨강, Enemy 피격 흰색, 보스 광역 피격 주황, 포션·휴식·레벨업 회복 초록 `+N`(회복량 0이면 표시 안 함).
  - 같은 프레임 여러 개면 살짝 위로 쌓이게. 사망한 대상도 숫자는 끝까지 재생.
- 기존 피격 플래시·`HitImpactVfx`는 유지.

## 2. 전투 로그
- **화면 하단 왼쪽**에 **최근 5줄** 전투 로그 (사용자 지정 위치). 기존 HUD(예: `M10ProgressionHUD`와 같은 화면 UI) 안에서 그린다. 새 Canvas·Singleton 금지.
- 문구 예: `goblin에게 36 피해` / `goblin에게 19 피해를 받음` / `광역 공격! 35 피해` / `대형 힐 포션: 즉시 +98` / `goblin 처치 +10 XP`.
- 오래된 줄은 위로 밀려 사라짐. 영지 씬에서는 표시 안 함. 원정 시작 시 비움.
- 텍스트 길이·위치는 미니맵·시계·레벨 HUD와 겹치지 않게 (스크린샷으로 확인).

## 3. 수치·설정
- 팝업 지속 시간·떠오르는 거리·로그 줄 수는 `m10_dungeon.csv`(예: `damage_popup_ms`, `damage_popup_rise_px`, `combat_log_lines`) 임시값.
