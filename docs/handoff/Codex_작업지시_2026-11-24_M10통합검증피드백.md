# Codex 작업지시 — M10 통합검증 피드백 반영 (2026-11-24)

근거: `docs/meetings/M10_DUNGEON_EXPANSION_DECISIONS_2026-11-20.md` 결정 33~37, M10 체크리스트 메모.
수치는 전부 CSV. 아래 수치는 사용자 결정 또는 "임시"로 표시한 값만 사용.

## 1. 몹 그림 3종으로 축소 (결정 33·34)
- 1~10층 일반·엘리트 몹은 모두 `sprite_key = goblin`. 보스는 그대로 (5F chest_mimic, 10F orc_warrior).
- `m10_enemies.csv`에 같은 그림·다른 스탯 행 추가 (enemy_id만 다름). 스탯은 **기존 값을 그대로 옮긴다**:

| enemy_id | tier | 층 | 스탯 출처 (hp/atk/def/xp/potion 등 모든 열 복사) |
|---|---|---|---|
| goblin | normal | 1~2 | 기존 goblin |
| goblin_f3 | normal | 3~4 | 기존 skelet |
| goblin_f6 | normal | 6~7 | 기존 wogol |
| goblin_f8 | normal | 8~9 | 기존 doc |
| goblin_elite_f3 | elite | 3~4 | 기존 masked_orc |
| goblin_elite_f6 | elite | 6~9 | 기존 ogre |

- `m10_floor_spawns.csv`: 각 층 normal_ids/elite_ids를 위 행으로 교체. 마리 수·엘리트 수(1~2층 0, 3·4·6~9층 1)는 그대로.
- 기존 몹 행(tiny_zombie 등)은 지우지 말고 남겨둔다 (이후 던전용). 심야몹(chort·imp·big_demon)은 건드리지 않는다 (M11).
- 비주얼 카탈로그·Validate Data가 새 enemy_id를 sprite_key로 정상 조회하는지 확인.

## 2. 엘리트 색조 진하게 (결정 34)
- `m10_dungeon.csv` `elite_tint_r/g/b` 100/72/72 → **임시 100/40/40**. 어두운 맵에서 일반 goblin과 구분되는지 스크린샷으로 비교 보고.

## 3. 대형 포션 70% (결정 35)
- `m10_potions.csv` potion_large `heal_pct` 100 → **70**. 다른 값 변경 금지.

## 4. 타일 단일화 (결정 36)
- 1~10층 바닥은 **바닥 타일 1종**, 벽은 **벽 타일 1종**만 사용. 랜덤 변형 타일(금 간 바닥, 함정처럼 보이는 타일, 이끼 벽 등)이 섞이는 경로를 찾아 제거.
  - `DungeonRunManager.floorTile/wallTile`이 랜덤·룰 타일인지, 장식(`m10_floor_decorations.csv`)이 바닥·벽을 덮는지 둘 다 확인.
- 장식은 끈다: `m10_floor_decorations.csv` 밀도를 0으로 (코드·CSV 구조는 유지).
- 층 테마 구분은 `m10_floor_themes.csv` 색조(floor_hex/wall_hex)만으로. 색조 값은 그대로.
- 문·계단·탈출구·상자 등 게임 오브젝트 타일은 건드리지 않는다.

## 5. 경험치 확인 (결정 37)
- `[M10XP]` 로그: 처치·첫 도착·빠른 도착 보너스 각각 (획득량, 사유, 현재 XP/레벨). 레벨업도 로그.
- F9 패널 레벨 줄 아래에 최근 경험치 획득 3건 표시. `#if UNITY_EDITOR || DEVELOPMENT_BUILD`, `docs/QA_DEBUG_TOOLS.md` 기록.
- F9 층 이동으로 도착했을 때 첫 도착 경험치가 들어가는지 확인. 안 들어가면 원인 보고 (임의 수정 금지).

## 6. 확인만
- 통합검증 로그에서 10층 orc_warrior 처치 시 `[RunRecord]`·`[BossLoot]` 로그가 안 보였다. 콘솔 Collapse 때문인지, 10층 처치 경로에서 실제로 안 불리는지 확인해서 보고. 실제 문제면 수정.
- `[RunRecord] 5층 보스 처치 기록` 문구가 10층에도 그대로 찍히면 층 번호를 넣게 수정.
