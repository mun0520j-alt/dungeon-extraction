## A. 심야 (결정 4~7) — DUN-88

현재 코드에 심야 시스템이 없음 (`DungeonClock.LockDisplayToMidnight()` 확장 포인트만 존재). 새로 만든다.

| 항목 | 내용 |
|---|---|
| 시작 | 원정 누적 **1,800Tick 이상**이면 심야 (`m11_time.csv` `night_start_ticks=1800`). 출발 06:00 기준 21:00. 끝은 없음(MIA 2,880까지 유지) |
| 상태 API | `IsNight`(또는 동등한) 한 곳에서 판단 + 진입 이벤트. 이미 심야 이후 층에 들어와도 바로 심야 |
| 진입 알림 | 심야 진입 순간 화면 문구 1회 + 전투 로그 1줄 (기존 HUD 사용) |
| 심야몹 | 그림은 goblin 그대로, **색조로 구분**: `night_tint` = **8C9CFF (임시, 푸른 밤색)**. 엘리트 외곽선과 겹쳐도 구분되게 |
| 심야몹 스탯 | 그 층 일반 goblin 행 × **`night_stat_pct=120` (임시)** (HP·공격), 방어 그대로, XP·포션 드롭 × 1.5 (임시). 기존 `night_floor_multiplier_pct`·chort/imp/big_demon 행과의 관계 정리해서 보고 (그 행들은 삭제 금지) |
| 심야몹 등장 | 심야 진입 시(또는 심야 중 층 진입 시) 그 층에 **2마리 (임시, CSV)** 추가 스폰, Player 시야·시작 방 밖. 보스 층(5·10) 제외 |
| 몹 위치 숨김 (결정 6) | 지금은 몹 위치가 다 보임 → 심야엔 **미니맵에서 몹 표시 숨김 + Player가 있는 방 밖 몹은 화면에서도 숨김**(같은 방이거나 N칸 이내면 보임, `night_reveal_range=4` 임시). 현재 몹이 어떤 경로로 다 보이는지(미니맵 카메라·Fog 등) 먼저 조사해서 보고 |
| 심야 보상 (결정 7) | 6~10층 레전더리 확률 **1% → 3%** (심야 중). 몹 드롭 수량 **1개 → 1~2개**: 1개 50% / 2개 50% (임시). `m10_loot_rarity.csv` 구조에 심야 열 추가 또는 `m11_time.csv` 배율 — 방식 보고 |

## B. 7층 탈출구 폐쇄 (결정 8·9) — DUN-87

- `seven_floor_exit_close_ticks=2220` (00:30, 06:00 출발 기준). **그 Tick 이후 7층 중간 탈출구는 즉시 닫힘** — 체류 중이었어도 완료 Tick이 2220 이상이면 실패(기존 M4 규칙 "완료 Tick 기준" 유지).
- 닫힌 탈출구: 색을 회색·어둡게, 진입 시 "탈출구가 닫혔다 — 10층 또는 탈출 스크롤" 안내.
- **탈출 스크롤은 폐쇄 후에도 사용 가능.** 3층·5층 탈출구는 영향 없음.
- 결과 우선순위 Dead > MIA > Escaped 유지. 2219/2220/2221 경계 TC.

## F. 월식 (결정 18·19) — 기존 기획 `ALTAR_AND_TIME_SYSTEM_DESIGN.md` 2~5장

- 흐름: 5층 미믹 처치 → 5층에 **제단지기 NPC** 등장(던전 안에서만) → 퀘스트 "멈춰버린 밤" 수락 → **같은 원정 안에서** 심야에 **월식의 파편** 획득 → 생환 시 완료 → 영지에 **월식의 제단** 생성 → 출격 준비에서 켜면 그 원정 내내 심야 상태(시계 표시는 `LockDisplayToMidnight` 활용).
- 파편 획득 위치 (임시): 심야 진입 후 6~9층 중 현재 층 이후 첫 일반층의 가장 먼 방에 빛나는 지점 생성, 줍기 2Tick. 사망·MIA 시 손실, 다음 원정은 미믹 처치부터 다시.
- 파편 스프라이트: 사용자 승인 대기 중인 Claude 초안 16×16 → 승인되면 경로 알려줌. 그 전엔 임시 스프라이트.
- NPC 스프라이트: 0x72 팩 NPC·영웅 중 하나 (적으로 쓰는 게 아니므로 결정 23 위반 아님) — 후보 보고.
- 제단 사용 시 심야 보상(A)·몹 숨김·7층 폐쇄 규칙 모두 처음부터 적용되는지 확인.
