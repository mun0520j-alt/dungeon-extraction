# Codex 작업지시 — M10 엘리트 붉은 외곽선 (2026-11-24)

## 배경
결정 34(엘리트 색 진하게)를 곱하기 색조(`elite_tint` 100/40/40)로 적용했더니 초록 goblin이 **거의 검은 갈색**이 되어 어두운 맵에서 더 안 보인다
(`QA/evidence/M10/elite_tint_comparison_100-40-40.png`). 곱하기는 어둡게만 할 수 있다.
사용자 결정(2026-11-24): **엘리트는 붉은 외곽선으로 구분.** 결정 회의록 결정 34에 "외곽선 방식"으로 갱신할 것.

## 구현
1. 엘리트 몹 Visual 뒤에 **실루엣 외곽선** 추가
   - 같은 스프라이트를 **상·하·좌·우 1px**(= 1/16 유닛, PPU 16) 어긋나게 4장 배치, 본체보다 sortingOrder 1 낮게.
   - 외곽선은 텍스처 색이 아니라 **단색 실루엣**이어야 한다. SpriteRenderer.color 곱하기로는 초록×빨강 = 어두워지므로 불가.
     알파만 쓰고 색은 단색으로 칠하는 재질을 사용 (예: 내장 `GUI/Text Shader` 또는 아주 작은 Unlit 실루엣 쉐이더). 빌드에서 빠지지 않게 Material 에셋으로 참조하거나 Always Included 처리.
   - 본체 애니메이션(`M10SpriteAnimation`)과 **같은 프레임·flipX**를 매 프레임 따라가야 한다 (LateUpdate에서 sprite·flipX 복사 등).
   - 엘리트 크기(visual_scale)·피격 플래시·사망 Destroy와 함께 동작. 피격 플래시가 외곽선 색을 덮어쓰지 않게.
2. 수치는 `m10_dungeon.csv`
   - `elite_outline_hex` = **FF3030 (임시)**, `elite_outline_px` = **1 (임시)**
   - `elite_tint_r/g/b` = **100/100/100으로 되돌림 (임시)** — 본체 원래 색 유지, 구분은 외곽선이 담당.
3. 일반 몹·보스에는 외곽선 없음.
4. 새 Canvas·Singleton 금지. 스크립트는 기존 구조(Visual 생성 지점 `DungeonRunManager` 486~514행 부근)에 붙인다.

## 검증
- 어두운 맵에서 일반 goblin vs 엘리트 goblin 비교 스크린샷 (이번엔 실제 Play 화면 또는 실제 렌더 기준) → `QA/evidence/M10/`
- 이동·공격·피격·사망 중 외곽선이 본체와 어긋나거나 남지 않는지
- `QA/TESTCASES_M10.md` TC-M10-61 갱신, `CHANGELOG.md`, `CODE_REVIEW_LOG.md`
