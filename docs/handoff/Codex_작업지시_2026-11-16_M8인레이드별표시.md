# 작업 지시 — M8 인레이드 목록 별 표시

- 일자: 2026-11-16
- 브랜치: `feature/m8-reputation-quest`
- 목적: 격자 마커만으로는 영지 목록에서 인레이드 여부를 구분할 수 없는 문제를 해결한다.

## 확정 규칙

1. 인레이드 아이템 이름 앞에 `★`를 표시한다. 예: `[Rare] [보험] ★ 기사의 검`.
2. 별 색은 격자 인레이드 마커와 같은 공용 색 값을 사용한다.
3. 목록 위에 `★ = 인레이드` 범례를 표시한다.
4. Stash 필터는 `★: 전체 → ★만 → ★ 아님` 순서로 순환한다.
5. 인레이드 판정·세이브 규칙은 바꾸지 않고 표시와 필터만 변경한다.

- `QA/M8_통합검증_체크리스트.md` 1-1~1-6
- `QA/TESTCASES_M8.md` TC-M8-01·24
- 격자 마커와 목록 별의 색이 동일한지 확인한다.
