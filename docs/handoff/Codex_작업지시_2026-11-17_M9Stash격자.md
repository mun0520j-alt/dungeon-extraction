## 1. 사용자 결정 요약 (원문: 회의록)

### 1-1. Stash 격자
- 목록 → 격자. M6 규칙 그대로(크기, R 회전, 드래그, 더블클릭 이동). Tick 없음.
- 10×20 시작. q03 완료 +2행, q06a 또는 q06b 완료 +2행, 최대 10×24. Stash 영역 세로 스크롤. **CSV** (`m9_stash.csv`: `base_width`, `base_height`, `rows_after_q03`, `rows_after_q06`).
- 확장은 퀘스트 보상으로만. 확장 시 기존 배치 유지, 아래쪽 행 추가.
- 자동 정렬(등급순/종류순). 부위·등급·★ 필터는 격자 하이라이트(안 맞는 아이템 흐리게).

### 1-2. 가방 보관함
- 가방 더블클릭 → 그 가방 격자 열기. 중첩 **최대 4단계**(Stash 직속 = 1단계). 4단계 가방 안에는 가방 불가 + 이유.
- 자기 자신·하위 가방 안으로 넣기 금지 + 이유.
- 내용물 있는 가방 장착 → 내용물 그대로 출격 가방. 판매 불가 + "가방을 비워주세요".
- **던전에서 출격 가방 안의 가방은 열 수 없다.** 아이템으로만 이동·버리기(내용물 유지). 시도 시 이유 표시, 0Tick.
- 사망·MIA 시 하위 가방 내용물 포함 전부 손실. 보험 반환 가방은 빈 가방.

### 1-3. 임시 보관함
- Stash 자리가 없을 때 들어오는 모든 아이템 → 임시 보관함(목록, 칸 제한 없음).
- 임시 보관함 → Stash·가방으로 옮기기, 판매.
- 임시 보관함이 비어 있지 않으면 **출격 버튼 비활성** + "임시 보관함을 정리하세요".
- 삭제 허용. 확인창 필수. 내용물 있는 가방 삭제 시 내부 아이템 일괄 삭제 경고.

### 1-4. 추가 확정·상점 판매 격자
- 운반 퀘스트(q03·q05a·q06b)는 하위 가방 내부 아이템까지 재귀적으로 센다.
- 장착 가방 해제 시 내용물을 유지한 가방 전체를 Stash로 옮기고, 공간이 없으면 임시 보관함으로 보낸다.
- 기존 개별 판매 버튼을 Stash 옆 **판매 바구니 격자**로 교체한다.
- 드래그·더블클릭으로 판매 바구니에 옮기며, 확정 전에는 Gold 변화가 없고 Stash로 회수 가능하다.
- `판매 확정` 시 여러 아이템을 원자적으로 판매하고 합계를 지급한다. 내용물 있는 가방은 이동 불가, 보험 아이템은 경고한다.
- 영지 행동이므로 0Tick. 판매 미확정 상태로 UI 닫기·게임 종료 시 원래 위치로 복구한다.
- 판매 바구니는 5×20 별도 격자이며 세로 스크롤한다. Stash와 같은 크기를 강제하지 않는다.

### 1-5. 세이브 v6
- Stash 배치(x, y, 회전), 가방 내용물(재귀), 임시 보관함. Stash 크기는 완료 퀘스트로 계산.
- v5 → v6, `save_v5.bak` 보존(실패 시 변환 중단). 기존 Stash 자동 배치, 넘치면 임시 보관함. q03·q06 완료 세이브는 확장 크기로.
- 로드 시 깊이 4 초과·자기 포함 데이터는 안전하게 처리(초과분 임시 보관함) + 경고 로그.
