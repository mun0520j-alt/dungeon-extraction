# Codex 작업지시 — M10 중간 탈출구 3·5·7층 + 표시 강화 (2026-11-24)

근거: 결정 회의록 결정 38~40. 기획 `docs/M4_WORKLIST.md` 44행 "장기 구조는 3·5·7·10층".

## 현재 상태
- `DungeonSceneBootstrapper.CreateFloorExit()`가 중간 탈출구를 `CurrentFloor == 3 || == FirstBossFloor(5)`에만 만든다 → **7층 누락**.
- 중간 탈출구 위치는 "계단에서 가장 먼 칸", 계단은 "리스폰에서 가장 먼 칸".
- 탈출구 표시: 흰 사각형 + `Color(0.2, 1, 0.75, 0.25)` — 너무 흐려서 안 보임 (`DungeonStairs.Initialize`).

## 수정
1. **중간 탈출구 층을 CSV로**: `m10_dungeon.csv` `mid_exit_floors` = `3;5;7`. 하드코딩 `== 3`·`FirstBossFloor` 비교를 이 목록으로 교체. 5층의 "미믹 처치 전 잠금" 규칙은 그대로.
2. **배치 (결정 40)**: 탈출구와 계단은 **리스폰 기준 서로 정반대 방향, 각각 가장 먼 칸**.
   - 계단: 리스폰에서 가장 먼 칸 (도달 가능).
   - 탈출구: 리스폰→계단 방향 벡터를 `v`라 할 때, 리스폰→후보 벡터와 `v`의 내적이 **0보다 작은 칸**(반대쪽 절반) 중 리스폰에서 가장 먼, 도달 가능한 칸.
   - 반대쪽에 후보가 없으면(시작 방이 맵 끝 등) 계단에서 가장 먼 도달 가능 칸으로 대체하고 `[M10Exit]` 경고 로그.
   - 거리는 가능하면 `TilePathfinder` 경로 길이 기준. 비용이 크면 맨해튼으로 하고 보고. 방향 판정은 좌표 벡터 기준.
   - 보스 층(5·10)은 아레나 배치 규칙 유지 (변경 금지).
3. **표시 진하게**: `m10_dungeon.csv` `exit_zone_hex` = **20FFC0 (임시)**, `exit_zone_alpha_pct` = **60 (임시)**. `DungeonStairs` 최종·중간 탈출구 색을 여기서 읽는다. 크기·체류 규칙은 변경 금지. 탈출 스크롤 구역(EscapeScrollZone)과 색이 헷갈리지 않는지 스크린샷으로 확인.
4. **7층 00:30 폐쇄는 구현하지 않는다** (결정 39, M11).
5. Validate Data: `mid_exit_floors`가 1~final_floor-1 범위인지, 보스 층 규칙과 충돌 없는지 검사.

## 검증
- Random Seed 여러 개로 3·7층에 탈출구 1개, 리스폰 기준 계단 반대쪽·멀리 생성 (대체 경로 발생 횟수도 보고).
- 7층 탈출구로 생환 → 결과 화면·보상 정상.
- 6~7층(swamp 색조)·8~9층 어두운 맵에서 탈출구가 보이는지 스크린샷 → `QA/evidence/M10/`
