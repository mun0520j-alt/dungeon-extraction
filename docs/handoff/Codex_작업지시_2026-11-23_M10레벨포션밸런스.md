## 1. 레벨 (결정 24·25·30)

- **원정마다 Lv1부터.** 원정 종료(생환·사망·MIA) 시 초기화, 영지에 남지 않음
- 레벨당 **최대 체력 +30, 공격 +1, 방어 +1** (Lv1 = 현재 기본 100/30/25). 레벨업 시 늘어난 최대 체력만큼 현재 체력도 회복(+30)
- 최대 레벨 12, 이후 경험치는 쌓지 않음
- 신규 `m10_levels.csv`: `level, cumulative_xp, hp_bonus, attack_bonus, defense_bonus` (Lv1~12)
  - 누적 경험치: 0 / 30 / 80 / 150 / 250 / 380 / 520 / 670 / 830 / 1000 / 1170 / 1340
- HUD: 현재 레벨·경험치 바(다음 레벨까지). 레벨업 시 짧은 표시
- 측정(M3) CSV에 도달 레벨 컬럼 추가

## 2. 경험치 (결정 29)

- 획득: **처치 + 층 첫 도착 + 빠른 도착 보너스**
- `m10_enemies.csv`에 `xp` 컬럼 추가: 1~5층 일반 10 / 1~5층 엘리트 40 / 미믹 100 / 6~10층 일반 25 / 6~10층 엘리트 90 / 오크 150 / 심야 몹은 같은 구간 엘리트와 동일(임시)
- `m10_dungeon.csv` 키: `floor_arrival_xp_shallow=20`(2~5층), `floor_arrival_xp_deep=60`(6~10층), `fast_arrival_ticks_per_floor=200`(층 × 200Tick 이내 도착), `fast_arrival_bonus_pct=50`
- 같은 원정에서 층 첫 도착 경험치는 층당 1회

## 3. 엘리트 출현 (결정 27)

## 4. 몹 수치 재조정 (결정 24·32, "1번: 몹 데미지로 포션 소모 강제")

설계 기준(레벨 포함): 일반 3~4타 처치·8~10타 생존 / 엘리트 6~8타·6~7타 / 보스 12~15타 처치, 포션 없이는 몇 대 못 버팀.
목표: **오크전 인파이트 시 대형 포션 약 4개, 미믹전 중형 포션 약 3개 소모.** 아래는 구간 기준값 — 같은 구간 몹끼리는 현재의 상대 차이(±5% 정도)를 유지해서 배분.

## 5. 힐 포션 (결정 31·32)

- 아이템 3종(items.csv, Consumable): `potion_small` 소형 힐 포션 Normal 1×1 / `potion_medium` 중형 Rare 1×2 / `potion_large` 대형 Epic 2×2. 판매가 임시 10 / 30 / 80
- 신규 `m10_potions.csv`: `item_id, heal_pct, duration_ticks, use_ticks` = 30/50/100 %, 10Tick, 2Tick
- 사용: 인벤토리 '사용'(기존 소비 아이템 흐름). 사용 2Tick, **최대 체력 × heal_pct를 10Tick에 걸쳐 균등 회복**
- 회복 중 다른 포션 사용 → **새 포션으로 다시 시작**(남은 회복량 버림, 중첩 없음)
- 회복 중 피격·이동·공격해도 **계속 회복**
- 하위 가방 안 포션도 사용 가능(탈출 스크롤과 같은 방식)
- 획득처:
  - 상점: 3종 판매(가격 = 판매가 × purchase_price_multiplier)
  - 상자: 등급 드롭 풀에 포함(drop_weight 임시값 CSV)
  - 몹 드롭: 처치 시 확률(`m10_enemies.csv` `potion_drop_chance` 컬럼, 임시값)
  - 퀘스트 보상: **보상 칸에 포션을 넣을 수 있게만**. 어떤 퀘스트에 줄지는 미정 — `m8_quests.csv` 실제 배정은 하지 않음
- HUD: 회복 중 표시(남은 Tick)
