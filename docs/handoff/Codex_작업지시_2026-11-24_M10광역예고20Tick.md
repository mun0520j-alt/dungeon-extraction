# Codex 작업지시 — 보스 광역 예고 20Tick (2026-11-24)

근거: 결정 회의록 결정 45. 사용자 QA: "틱은 다 2배인데 보스 광역기 틱은 그대로", "공격 틈이 너무 적다".

## 현재
- `EnemyTurnActor.RunBossTurn()`: 예고 시 `minimumNextActionTime = globalTime + 5f` (388행), 로그 "5 Tick 뒤 발동" (379행) 하드코딩.
- 예고가 단일 공격(10Tick)과 같은 턴에 붙어서, 실제로는 보스 다음 행동이 약 10Tick 뒤 → Player가 공격(10Tick) 한 번 하면 그 사이 발동.

## 수정
- `m10_dungeon.csv` `boss_aoe_telegraph_ticks` = **20** 추가. 예고 시점(전역 Tick)부터 **정확히 20Tick 뒤**에 발동하도록 `minimumNextActionTime = globalTime + 값`.
- 예고 로그·텔레그래프 표시 문구도 CSV 값 사용.
- 미믹·오크 공통. 광역 피해·범위·이펙트는 변경 금지.
- 회귀: 기존 TC(예고 후 1~4Tick 미발동, 5Tick 발동 — BUG-031 부근)를 **19Tick 미발동 / 20Tick 발동**으로 갱신. 보스 사망 시 예약 광역 취소, BUG-052 무한 루프 가드 유지 확인.
- Validate Data: 값이 TickCost.Attack(10) 이상인지 검사.

## 같이 확인만 (수정 금지, 보고)
- 결정 14 "Tick 2배" 대상 중 아직 옛 값으로 남은 하드코딩이 더 있는지 전수 조사해서 목록으로 보고. 예: `PlayerTurnActor.ResolvePendingRestHeal` 휴식 회복 10Tick당 +10(보스 후 +20) — 이건 사용자가 휴식 방식을 다시 정할 예정이라 **건드리지 말 것**.
